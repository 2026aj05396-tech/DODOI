dodoi companion Talking about: Pipe cleaner bonsai
I only have white pipe cleaners. Will it still work?
Yes. The shape comes from twisting, so color doesn't change the steps. Two options: 1. Make a snowy "winter bonsai" and keep it white. 2. Color the leaves afterwards with a green marker. Test on one stem first, as some markers bleed.

1 dodoi — core mobile PWA flow
Scope

Phase 1–4 journey on mobile: welcome → interests → feed → explore → tutorial → AI companion → journal → community help → profile. Desktop and edge states come next.

Visual system

Pastel palette on a dotted cream paper base: soft coral for actions, lavender stripes for "new to you", and butter, blush, lavender, mint and sky tiles carrying craft-inspired patterns (polka dots, ticking stripes, gingham, scallops, checks).

Principles in the UI

No public scores or like counts. Post types (first attempt, WIP, journal) are first-class labels. AI is a context-aware pill, not a separate app.

Placeholders

Colored tiles stand in for user photos. Interactive: interest chips, feed filters and save buttons.

Why does my edge look so wavy?
A wavy edge usually means too many stitches per round. From the photo, your last two rounds look like they have extra increases.
1. Count the stitches in your last round. 2. Compare with the pattern total. 3. If you're over, frog back one round and redo it.
